The shared queue at `/tmp/goal-flight-501/dispatch-queue` has become a
cross-project graveyard: entries aged from hours to ~4 days, almost all

The doctrine, which constrains your output: **a queued dispatch carries a
PREMISE, and premises go stale.** Nobody may bulk re-fire these — that would
manufacture a large volume of confident work against unchecked premises. So
the deliverable is an inventory that lets each project's controller decide
per entry, quickly, whether the work is still wanted.

**It also lives in /tmp, which macOS reaps.** Persisting this accounting
